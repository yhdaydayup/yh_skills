# 措辞规范

总原则：**把话说简单，说明白。不说让人迷惑的话，不说没有有效信息的话，去掉当前语境下没有作用的话。**

删留判断方法只有一条：**解释某个判断或某个做法的留，只给结论镶边的删。**

正面例子（保留）：「各图分母是不同市场，只能逐个读」——它解释了为什么四张饼不能横向相加，删了读者就不知道原因。
反面例子（删除）：「三条理由，彼此不依赖」——「彼此不依赖」没有增加任何可验证的信息。

## 一、病句五类

| 类型 | 原文 | 改后 |
|---|---|---|
| **比喻代替事实** | 底下还压着两家上市子公司 | 持有的两家上市子公司股权，市值比它自己高 29% |
| **虚化实词** | 万洲**本质上**是肉制品加工公司 | 万洲是肉制品加工公司 |
| **无功能连接词** | **换句话说**，FY2025 的扩张是靠债权人和新股东出的钱 | FY2025 的扩张是靠债权人和新股东出的钱 |
| **作者自评** | **需要公允地补一点**：放在同业里海底捞是最抗跌的 | 放在同业里海底捞是最抗跌的 |
| **对读者的承诺** | 一、投资结论——**这一屏读完就能决策** | 一、投资结论 |

最后一类的判断依据：**做到了不用说，没做到说了更糟。**

## 二、黑话黑名单

左列一律不许出现，校验器会拦。

| 不要写 | 要写 |
|---|---|
| 底下压着两家公司 | 持有的两家上市子公司股权，市值比它自己高 29% |
| 三根支柱 / 三根独立支柱 | 买入逻辑有三条 |
| 彼此不依赖 / 三者不需要同时兑现 | （删除，不要补充说明） |
| 欧洲业务白送 | 欧洲业务没有计入这 151 亿 |
| 在派家底 | 派的是账上存量现金 |
| 靠两项撑住 | 两项相互抵消 |
| 行业天花板 | 回报上限 |
| 猪周期击穿盈利 | 猪价下行不足以让集团整体转亏 |
| 一图看全貌 | （删掉标题，图本身会说话） |
| 钱是谁赚的 / 钱到底是谁赚的 | 收入和利润分别来自哪里 |
| 值得注意的是 / 不难看出 / 可以看出 | （删除） |
| 代价写在现金流上 | 但自由现金流在倒退 |
| 已经 price 进去了 / price in | 已经计入了一部分 |
| 不是白送的 | 没有计入任何余量 |
| 击穿盈利能力 | 不足以让盈利能力转向 |

**英文术语混在中文里也算黑话。**「代价写在现金流上」被用户直接批「这个就是黑话，谁看得懂」，
同一轮里我自己又写出「已经 price 进去了」「AI 原生办公 agent」「token 消耗量」——
**写的时候顺手，读的时候全是坎**。中文能表达的一律用中文：agent → 智能体，token 消耗量 → 模型调用量。
校验器只能拦已经登记过的词，**新造的黑话得靠交付前自己通读一遍**。

注意：实测发现**啰嗦不是用词问题**。全文扫「值得注意的是／换句话说／不难看出」这类填充词，
两份报告加起来只找到一处。**膨胀 90% 来自往常态可见层里塞了不该在那儿的东西**，见下节。

## 三、篇幅膨胀的四个真实来源

| 来源 | 表现 | 处理 |
|---|---|---|
| **考据留在了外面** | 一段说明 1,333 字，结论只有前三句，后面九百多字是四条分母的数据出处和口径限制 | 收进 `<details class="fold">` |
| **草稿残留** | 「与本报告早前版本的差异：FY2025 分母此前用的是美国 12,500……现全部替换为」「本表刻意并列多个数而不给单一结论」 | 删。读者不关心上一版写了什么，也不关心编排意图 |
| **用文字把图上能看见的东西再念一遍** | 「① 营收（青色）是一条平线：指数 100→104。② 归母净利涨到 145。③ 每股股息涨到 321……」 | 只留图上看不到的：为什么会这样、意味着什么 |
| **跨章重复** | 第四章讲过的「2027 三重叠加」，第七章风险清单原样复述 | 后者改成一行带锚点的引用 |

另有一类元评论开场，一律删除，不要在前面加一句「这个很重要」：

- 「这张图揭示了合并报表掩盖的真相」
- 「这组数据揭示了一个对海底捞非常不利的行业背景」
- 「这张图提供了一个此前分析里缺失、而且对结论重要的视角」

**要强调重要，就把结论写硬，不要给它加前缀。**

### 界面术语要写成动作，不要写控件名

图表说明里写「原值在 tooltip 里」，用户的反馈是「**tooltip 在哪？**」。
`tooltip` 是开发者的词，读者不知道它指什么、更不知道怎么触发它。
**要写成读者能照做的动作**：「把鼠标停在线上任意一个圆点，会浮出该点的原始数值（手机上点一下圆点）」。
同类：hover → 把鼠标停在……上；legend → 图例；canvas → 图。
这条最初只错在骨架里一处，但三份报告都是照骨架抄的，于是一起错——
**骨架里的每一句文案都会被复制 N 次，改骨架比改报告优先。**

## 四、专业术语首次出现必须给定义

报表附注里的内部术语直接搬进图表标注，读者会卡住。**「对外收入」被连问两轮**，
因为在集团层面「营业收入」本来就是对外口径，读者不理解为什么要换个词。

规则：**用了年报附注的术语，就在同屏给一句定义，说明它和读者熟悉的那个词差在哪。**

> 对外收入 = 该分部卖给集团外部客户的收入，已扣除卖给集团内其他分部的部分。
> 各分部对外收入之和等于合并利润表的营业收入；用「总分部收入」相加会因分部间互相卖货而重复计算。

同类需要给定义的：地区构成 vs 区域市占率、名义 PE vs 真实 PE、经常性股息 vs 含特别息、
简化自由现金流 vs 真实自由现金流、批发份额 vs 零售份额。

## 五、标题写法

- **标题只写内容。** 不写「一图看全貌」这类虚标题，不写「钱到底是谁赚的」这类口语化设问。
- **口径说明不进标题。** 「生猪屠宰头数（物理量口径）」→ 标题写「生猪屠宰头数占比」，
  口径说明降级成后面的灰色小字（下游还要靠它区分两节不可比，所以保留但不占标题）。
- **铺垫改成总结。** 「这一节只有三个结论，不想看细节可以直接跳过后面的图表：」→「本节总结」。
- 小标题用规范表述，不用口语：
  「A. 万洲自己的屠宰量，国内外怎么分」→「A. 地区构成 —— 屠宰量在各地区的分布（FY2025，万头）」。

## 六、结论表述

- **结论先行。** 每个区块第一句就是判断，论据在后。
- **评级只用三档**：买入 / 观望 / 回避。给价格区间和触发条件，不给模糊的「可以关注」。
- **入场条件分「价格条件」和「基本面条件」两类**，并说明哪个更重要。
  例：跌至 HK$7.5 以下（价格），或连续两个报告期同店销售转正且人均消费止跌（基本面，更重要）。
- **结论被新证据推翻时直接说推翻了哪一条**，不要悄悄改掉。
  例：「原报告第 6.3 节的结论是错的。我之前只看应付账款，得出账期在持续改善……」
- 免责声明放页脚，一句话，不要在正文里反复声明。
