# 页面批注 Page Comment

在网页上选中文字或点击元素直接写评论，导出成带**章节路径 / 位置 / 选中原文**的反馈清单，
不用再用文字描述「第三章那个图的右边那条线」。

## 安装

1. 解压到任意目录（别放在会被清理的临时目录里，Chrome 需要长期读取它）
2. 打开 `chrome://extensions/`
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选中解压出来的 `page-comment` 文件夹
5. 如果要批注本地 `file://` 打开的页面：在扩展详情页把「**允许访问文件网址**」打开

## 用法

| 操作 | 怎么做 |
|---|---|
| 给一段文字加批注 | 选中文字，按 `c`，或点旁边弹出的「＋ 评论」 |
| 给图表 / 图片加批注 | 点面板里的「◎ 点元素」，再点目标或按 `c`（Esc 退出） |
| 打开 / 关闭面板 | 点工具栏图标，或 `Alt+Shift+Y` |
| 直接进元素模式 | `Alt+Shift+E` |
| 保存 | `Enter`（`Shift + Enter` 换行，`⌘/Ctrl + Enter` 同样有效） |
| 导出 | 面板底部「复制全部反馈」，粘贴即可 |

批注按「域名 + 路径」分别保存在本地，刷新和重开浏览器都还在，不上传任何数据。

`c` 是单键，所以做了几层避让：光标在输入框或 contenteditable 里时不接管；
`⌘C`／`Ctrl+C`／`Alt+C` 一律放行（否则复制就废了）；编辑框已经打开时 `c` 就是个普通字符。
没有选中任何东西时按 `c` 不会开空白批注，只给一句提示。

`Enter` 直接保存，空白内容会被拦下并提示，不会存进去。中文输入法选词的那个回车不算确认——
不挡住 `isComposing`，打一半的拼音会被当成批注存下来。要换行用 `Shift + Enter`。

面板级快捷键用的是 `Alt+Shift+Y` / `Alt+Shift+E`，而不是更顺手的 `Alt+Shift+C`——实测 Chromium 里
`Alt+Shift+A`、`Alt+Shift+C`、`Alt+Shift+P` 都已被占用，声明了也会被静默丢弃。
想换成别的组合，在 `chrome://extensions/shortcuts` 里直接改。

## 导出长什么样

```
页面批注 · 万洲国际 0288.HK — 独立投资分析
https://example.com/whgroup-analysis.html
2026-09-24 11:30 · 共 2 条

[1] 五、行业地位：万洲在各个市场分别占多少份额 › 生猪屠宰头数占比
    位置  正文文本 @ #s5
    原文  「美国份额在流失：25.13%（FY2021）→ 23.30%（FY2025）」
    意见  这段太长了，砍一半

[2] 一、投资结论 › 关联指标合并趋势图
    位置  canvas#cCore
    意见  图例挡住线了
```

`位置` 和 `原文` 两栏是给接收方定位用的：`canvas#cCore` 能直接对应源码里的图表 id，
`原文` 能直接拿去全文检索。

## 适用范围

`content_scripts.matches` 是 `<all_urls>`，任何 http/https 页面都能用，不限于本项目的报告。
以下是实测过的边界：

| 场景 | 结果 |
| --- | --- |
| 普通 http/https 网页 | 可用 |
| Shadow DOM（Web Component）里的文字 | 可用，锚点会钻进开放 shadow root |
| `<details>` 折叠块 | 展开后可批注；合上时浏览器本身就选不中文字 |
| `file://` 本地文件 | 需在扩展详情页手动打开「允许访问文件网址」 |
| `chrome://`、Chrome 应用商店、其他扩展页 | Chrome 禁止注入，插件不会出现 |
| `<iframe>` 内部 | 不可用（`all_frames: false`，避免每个 frame 各弹一个面板） |
| Chrome 内置 PDF 阅读器 | 不可用 |
| 闭合 shadow root（`mode: 'closed'`） | 不可用，页面自己也拿不到 |

其他要知道的：

- 批注按 `origin + pathname` 分组存放，**查询串不参与区分** ——
  同一路径不同参数的页面共用一份批注
- SPA 用 `pushState` 换路由会被识别成换页，各存各的；
  hash 路由（`#/foo`）算不同页面，普通锚点（`#s1`）不算，跳目录不会把批注拆散
- 存在 `chrome.storage.local`，只在本机本浏览器，不同步、不上传。
  同一页开多个标签页会实时互相同步
- 保存失败（如超出 10MB 配额）会回滚并明确提示，编辑框内容不丢
- 删除和清空都有 8 秒撤销窗口，所以清空不再弹确认框
- 图表只能整张批注，没法标到图里的某个点 —— canvas 内部没有 DOM

## 页面改了之后会怎样

两种批注的锚定方式不同，抗变更能力也不同。

**文字批注**锚的是选中的那段字本身：整页可见文本拉平成去掉空白的字符串，
记下字符区间、前后各 40 字、以及第几次出现。所以——

- 结构重排、包容器、改 class、整段节点被替换成等价新节点：**不受影响**
- 页面前面插入大段内容导致位移：**不受影响**
- 页面前面新增一处一模一样的文字：靠前后文消歧，**不会被抢走**
- 锚点落在收起的 `<details>` 里：点定位时**自动展开**沿途折叠块
- 锚定的那几个字被改写、或整段被删除：**失锚**

**元素批注**（图片、图表、图标、按钮）按「CSS 路径 → 元素指纹 → 原文检索」三级回退。
指纹记 `src` / `alt` / `aria-label` / `title` / `name` / `class`，专门对付
没有 id 又没有文字的元素 —— 这类元素只靠 `nth-of-type` 路径，结构一变就断。
路径与指纹冲突时以指纹为准，但同 `src` 同 `alt` 的重复元素靠路径分辨，不会互相抢。

失锚的条目会在面板里标灰显示「页面上已找不到」，**评论内容不会丢**，导出时照常带上。
